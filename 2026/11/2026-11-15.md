# 2026-11-15

## What I tried
Setting up this log, and working out how building with Claude Code turns into visible activity on GitHub.

## What I learned
Claude Code's work doesn't show up on GitHub by itself. Only commits that are pushed to a repo's main branch count, and they have to come from an email address linked to the account. Pull requests, issues and reviews count too. If a repo is private, it only appears on the contribution graph once "Include private contributions" is turned on.

## So what
The simplest habit: end every Claude Code session with "commit and push to main." Then the record builds itself as a side effect of real work, with no separate step.
