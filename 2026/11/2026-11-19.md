# 2026-11-19

## What I tried
Getting this log properly live: uploading the first files through GitHub's website, connecting the Claude extension in Chrome, and turning on private contributions on my profile.

## What I learned
Files uploaded through GitHub's website count on the contribution graph straight away, because GitHub credits the commit to whoever is signed in. Commits made elsewhere, like through Claude Code, only count if their email matches one on the account. Getting the Claude extension to connect took a Chrome restart: being installed and signed in wasn't enough until Chrome finished its pending update.

## So what
The setup friction is mostly a one-off. Once the browser is connected, Claude can commit an entry straight from a conversation, so the daily habit shrinks to saying what I learned.
